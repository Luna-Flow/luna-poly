# consistency API

## Purpose

`Luna-Flow/luna-poly/consistency` has no public items: its interface file is empty. It is a whitebox test package that imports both facades and checks that the immutable and mutable layers, and the different representations, compute the same results. The checks it performs are described in the [consistency design](../design/consistency.md).

## Importing

There is nothing to import. The package is listed because the Luna Flow documentation standard asks for a page per package; run its tests with `moon test`.
