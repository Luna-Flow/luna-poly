# consistency API

`Luna-Flow/luna-poly/consistency` has no public items: its interface file is empty. It is a whitebox test package that imports both facades and checks that the immutable and mutable layers, and the different representations, compute the same results.

It is listed here because the Luna Flow documentation standard asks for a page per package; there is nothing to call. The checks it performs are described in the [consistency design](../design/consistency.md).
